Details & testing approach

What it does

  • Create, view, update and delete records through Flask routes (full CRUD)
  • Data stored in MySQL through SQLAlchemy ORM models (PyMySQL driver)
  • Frontend sends asynchronous Fetch API requests, so pages update without full reloads
  • Database schema changes versioned with Flask-Migrate / Alembic migrations
  • Responsive interface built with HTML, CSS, JavaScript and Bootstrap

How it can be validated

  • Functional Each screen and API route behaves as specified
  • Form validation Required fields, formats and error messages
  • CRUD Create, read, update and delete records end to end
  • Boundary Empty, maximum-length and edge input values
  • Negative Invalid input and unexpected requests are rejected cleanly
  • DB validation What the UI shows matches what MySQL stores
  • UI Layout, states and feedback across screen sizes
